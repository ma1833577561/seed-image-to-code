# OpenSpec 05：验收标准（Acceptance）

## 1. 分级验收

| 目标还原度 | 验收项 | 通过条件 |
|------------|--------|----------|
| 85% | 元素无缺失、布局结构正确、代码可运行 | 综合分 ≥ 85 |
| 90% | 主色/字号/核心间距匹配、无明显布局错位 | 综合分 ≥ 90 |
| 95% | 圆角/阴影/图标/次级间距细节达标 | 综合分 ≥ 95 |
| 99.99% | 像素 diff < 0.01%、四维分项均 ≥ 99 | 综合分 ≥ 99.99 |

## 2. 验收证据链

每档验收必须包含：输入 → 关键过程（评分 JSON、问题清单、迭代记录）→ 最终结果（渲染截图、综合分）。证据链不完整视为未通过。

## 3. 真实性约束（红线）

- 禁止修改评分公式、跳过像素校验、删除问题项制造达标结果。
- 99.99% 受字体渲染、动态内容、抗锯齿、懒加载影响可能无法稳定达成，必须如实反馈。

## 4. 终态

- `completed`：目标达成，结束并等待下一步指令。
- `waiting_user`：10 个开发-测试-验收周期后仍未达 99.99%，保留最佳产物，停止操作等待用户指令。
- `stage-exception`：阶段执行异常（如实记录原因）。
